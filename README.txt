LUIGI5MASH GAMING OS — PWA V1

This folder is a Progressive Web App.
It must be hosted over HTTPS for iPhone Home Screen installation and offline service-worker support.

HOSTING:
Upload the contents of this folder to any static HTTPS host (for example GitHub Pages, Netlify, Cloudflare Pages, or Vercel).
The host should serve index.html at the site root.

IPHONE INSTALL:
1. Open the HTTPS site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch Gaming OS from the new Home Screen icon.

V1 DATA:
Game/quest/session data is stored locally in that browser/device.
Use Export Save / Import Save to move data manually between devices.
Cloud sync is intentionally not part of V1.
